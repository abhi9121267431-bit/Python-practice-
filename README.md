My Python practice programs and beginner projects as I learn programming and backend development.
Student Management System
A beginner-friendly Student Management System built using Python.
##Features
Add student records
View all students
Search students by roll number
Update student details
Delete student records
Calculate grades automatically
Display pass or fail status
Generate a class summary report
Save student records in a JSON file
Technologies Used
Python
JSON
File handling
Basic data structures and functions
How to Run
Install Python.
Download or clone this repository.
Open the project folder in VS Code.
Run the following command in the terminal:
python student_management.py
If your system uses python3, run:
python3 student_management.py
Data Storage
Student records are saved in students.json so they can be loaded again when the program runs.
Learning Outcomes
This project helped me practise Python functions, loops, conditions, lists, dictionaries, exception handling, and JSON file handling.
