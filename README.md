Student Management System
A beginner-friendly Student Management System built using Python. This project helps manage student records and practise fundamental Python programming concepts.
Features
Add student records
View all students
Search students by roll number
Update student details
Delete student records
Calculate grades automatically
Display pass or fail status
Generate a class summary report
Save student records using JSON
Technologies Used
Python
JSON
File handling
Lists and dictionaries
Functions and exception handling
How to Run
Install Python.
Download this repository from GitHub.
Open the project folder in VS Code.
Run the following command in the terminal:
python student_management.py
If required, use:
python3 student_management.py
Data Storage
The program stores student records in a students.json file so that records can be loaded again when the program runs.
Learning Outcomes
This project helped me practise Python functions, loops, conditional statements, lists, dictionaries, exception handling, and JSON file handling.
